# ToPoGate baseline comparison release

This release contains the reproducibility code and audit/summary metadata for
the 2026-09-10 baseline comparison. It intentionally excludes raw datasets,
labels, per-sample predictions, embeddings, checkpoints, and model weights.

The formal matched-budget panel currently contains KMeans, PCA+KMeans, and
ToPoGate_strict8. Remaining requested external/biology baselines are recorded
as incomplete or protocol-incompatible in the audit files.

The complete persistent archive remains on the authorized server and in the
local workspace path documented in the final handoff.
