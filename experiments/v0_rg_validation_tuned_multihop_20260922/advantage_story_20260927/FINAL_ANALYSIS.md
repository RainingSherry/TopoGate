# ToPoGate 多跳优势机制：本轮实验结果

本轮最有价值的新增结论是：**在三个冻结案例中，沿局部图路径组织来源，相比逐样本候选数相等的直接宽kNN，将更多候选概率分配给一阶未覆盖的社区，并同时获得更好的聚类和同类跨社区整合。** 这比“多跳收集了更多信息”更具体：数量对照相等，观察到的差异是来源范围、分配结构以及群体关系。

## 执行与口径

SSH yazhouwan，仅GPU2/4，21个新增训练全部成功（12个固定深度补项、9个Kwide），24个历史训练单元复用。59个背景数据集的读出分析全部成功；三个案例各15个策略×seed单元、150个读出完成；五seed真实来源轨迹和九组checkpoint响应分析完成。新增权重、原始轨迹留在远端，同目录轻表图和审查记录已同步。训练记录均确认test_labels_loaded=false、labels_used_for_model_fit=false、core_source_unchanged=true；benchmark K沿用已声明的类别数设定。标签仅在事后ARI、来源类型和群体关系分析中使用。

所有对比固定已有validation选择的参数，不使用本轮全X结果再次挑选参数。每个训练seed先对10个KMeans读出取均值，再汇总3个训练seed。Baron真实trace使用另一个独立的5seed组，不能与3seed读出拼成同一配对估计。

## 1. 为什么值得研究多跳

本轮统一读出后，59个匹配数据集中44个平均ΔARI为正、10个负、5个平；22个在三个训练seed均正，30个同时减少同类拆分与异类合并。这些数据集来自此前排名筛选的队列；44/59描述的是该队列的重复收益，不能估计任意数据集的成功率。它构成值得深入解释的问题背景。

历史归档显示46个正值；本轮在相同embedding上重新计算读出后，两项接近零的结果翻号。最终论文应统一用本轮44/59，历史46/59另作来源记录，不能混用。三个主案例的读出结果与历史完全一致。

对应产物：RESULT_E1.md、RESULT_E3.md、outputs/E3_cohort/partition_gain_plane.pdf。

## 2. 三个案例回答同一问题的不同侧面

| 案例 | H1 ARI | 锁定多跳 ARI | ΔARI | 主要观察 |
|---|---:|---:|---:|---|
| Baron H8_B1 | .771040 | .837703 | +.066663 | 同类拆分减少，新增来源可以定位到跨社区同类群体 |
| Quake Lung H8_B2 | .706870 | .738201 | +.031330 | H2/H4改善较小，H8进一步改善跨社区整合 |
| student_grade H4_B1 | .328167 | .367869 | +.039701 | 聚合与分离同时改善；四阶后可达范围饱和 |

三个案例均3/3训练seed正向。student三seed ARI为H1 .328167±.015526、H4 .367869±.012220、Kwide .350063±.021067（均值±训练seed标准差，每seed先平均10个读出）；这属于描述性改善，不以三个seed宣称统计显著性。共同主线不是“三种不同算法机制”，而是**局部来源范围限制了哪些群体关系可参与训练；路径扩展改变了这些关系的覆盖和组织。** 其具体表现取决于图的可达范围与当前聚类错误。

在固定输入图社区上，同类跨社区共同分配率分别提高11.95、4.64、2.82个百分点；社区内原本已有较高一致性。这将收益定位到局部群体之间，而不仅是展示更好看的二维散点。

对应产物：RESULT_E4.md；outputs/{Baron,Quake_Smart-seq2_Lung,student_grade}/中的完整关系表和矩阵图；outputs/E4_layouts/case_layouts.pdf为三案例统一布局总览，颜色显示逐样本跨社区同类共同分配率。布局固定于输入数据，不代表学到的embedding位移。

## 3. 为什么不能只增加邻居数量

| 案例 | path / Kwide平均候选数 | 新社区候选概率质量 path / Kwide | ARI path / Kwide | 跨社区同类共同分配 path / Kwide |
|---|---:|---:|---:|---:|
| Baron | 239.35 / 239.35 | 40.33% / 2.40% | .837703 / .783289 | 69.60% / 59.75% |
| Quake Lung | 110.71 / 110.71 | 28.54% / 9.22% | .738201 / .703739 | 61.65% / 56.40% |
| student_grade | 90.68 / 90.68 | 14.76% / 5.91% | .367869 / .350063 | 61.90% / 60.33% |

候选数量已逐anchor核对相等；原图、gate、抽样次数、encoder、恢复目标与训练预算相同。三个案例中，直接扩大k仍较多地集中在一阶已覆盖的社区；路径组织让其他局部群体以更大概率成为扰动来源，并伴随更好的跨群体整合。这组“来源结构—关系变化—ARI”的对应，是论文最适合前置的新证据。

这里检验的是路径构造及其来源权重组成的整体方案；来源方向和实际位移没有被强行匹配，不能将全部差异归因到单独的路径身份。该界定写进实验设置即可，不必在每段重复。

对应产物：RESULT_E2_E6.md；outputs/E2_E6/各例深度图、覆盖表、候选计划、读出和cross_coassignment_summary.csv。

## 4. 新增来源具体包含什么

Baron五seed共13,710,400条真实来源记录表明：38.93%的邻域混合权重来自一阶未覆盖社区，其中21.45个百分点来自同类跨社区样本，17.48个百分点来自异类样本。约80%的同类跨社区来源权重来自这些新增社区。分母是gate前的邻域混合，不是最终输入。

进一步将关系统计对齐到trace所用的同一社区划分：alpha类新增同类来源权重25.43%，其跨社区同类共同分配从17.58%升至46.67%；beta相应为34.10%，共同分配从87.98%升至92.63%。这两个大群体构成可讲清楚的具体案例：新来源接触到了局部邻域外的同类片段，改善发生在这些片段之间的整合。

全部类别表同时保存；ductal来源权重高但整合未改善，gamma来源增量很小但共同分配上升。因此不把来源占比当成收益大小的公式，也不称逐路径因果证明。主文可以围绕alpha/beta解释实际现象，以完整逐类结果保证描述的边界。

对应产物：RESULT_E5_SOURCE.md；outputs/E5_trace/source_role_distribution.pdf；outputs/E5_shared_partition/class_source_relation.csv。

## 5. 有效深度由实际来源范围决定

Lung的H1/H2/H4/H8平均ARI为.70687/.71380/.71348/.73820，较远范围提供了额外改善。student的H2未改善，H4达到.36787；H4与H8的候选节点、概率、阶数和embedding逐元素相同，最大实际阶数为4，因而更大的名义跳数不会新增来源。

Baron的H2与H8平均ARI相近；H8的三个seed波动较小，但不能把三seed描述性差异升级为稳定性定律。这一结果适合说明：研究对象是有用来源范围，而非追求更高跳数。236个已有固定有效参数的完整三seed深度组作为背景热图，缺失位置明确保留。

## 6. 响应探针放在辅助位置

同anchor、同方向的checkpoint探针显示，真实数据来源方向与等范数随机方向产生不同响应；但H1与multihop的归一化latent响应相近，不能作为multihop独有能力的证据。Baron与Lung在两个固定扰动幅度、三个seed下均降低了原anchor重构MSE增量，可作为恢复约束的辅助观察；student不呈现同样一致的幅度趋势。

该探针没有mask/gate缩放，方向来自标明近似浮点匹配的重建plan Monte Carlo，不能冒充训练回放或真实生物噪声恢复。主文的重心应留在来源结构与关系整合，完整response图适合补充材料。

对应产物：RESULT_E5_RESPONSE.md和outputs/E5_response/response_probe.pdf。

## 论文可以采用的主张

**ToPoGate通过沿局部图路径扩展训练扰动来源，接触一阶邻域未覆盖的群体关系。在选定的多跳受益案例中，这种来源组织比等候选数的直接宽kNN更有效地支持跨局部群体整合，并提高聚类性能。有效范围由数据图的可达结构决定，名义上增加跳数本身不是目标。**

方法部分需要准确说明：跳数指固定图上的来源构造范围，不是堆叠GNN层数；邻域混合作为输入扰动、原样本作为恢复目标，encoder结构在本轮对照中保持不变。与其他模型的区别应落在该来源组织和训练用途上；本轮没有运行GDC/MAGIC等新基线，不应借结果宣称全面胜过这些方法，也不把混合协议的历史Top1称为统一SOTA。

建议实验顺序：59队列背景 → 固定深度曲线 → 等数量来源组织对照 → 三案例关系图 → Baron真实来源及alpha/beta展开；响应探针和完整逐类/逐seed表放补充。这样每节回答上一节留下的问题，而不是按任务完成顺序堆数值。
