# E2与E6：扩大到哪里，比增加多少候选更能解释结果

固定非深度配置，三例H1/H2/H4/H8和候选数匹配Kwide全部完成：每例15个训练单元（历史复用与新增训练分别记录）、150个读出，先10读出均值、再3训练seed汇总。本轮共补12个深度训练和9个Kwide，不是重训全部45个单元。

|---|---:|---:|---:|---:|---:|---:|
| Baron | .771040 | .837090 | .772907 | .837703 | .783289 | +.054414 |

锁定path分别为H8_B1、H8_B2、H4_B1，没有按这些全X结果重新选择配置。Baron的H2与H8平均ARI相近，H8的三seed SD较小（.0265 vs .0540）；不应据此说八阶在Baron绝对必要。Lung在H8才出现较明显的额外改善，student在H4得到改善。

student的范围饱和有直接实现证据：三个seed的H4重建plan与H8实际保存plan的offsets/nodes/probs/hops/draw_count完全相同，最大实际阶数均为4，两个embedding也逐元素完全相同。因此H8没有新增可获取来源，结果相同不是KMeans巧合。这把“有效深度”连接到了数据图的实际可达范围。

## 数量匹配后的结构差异

| 数据集 | 每anchor平均候选数（path=Kwide） | 新社区候选概率质量 path / Kwide | 跨社区同类共同分配 path / Kwide |
|---|---:|---:|---:|
| Baron | 239.35 | 40.33% / 2.40% | 69.60% / 59.75% |
| Quake Lung | 110.71 | 28.54% / 9.22% | 61.65% / 56.40% |
| student_grade | 90.68 | 14.76% / 5.91% | 61.90% / 60.33% |

候选数相等已逐anchor逐seed检查，而不仅是均值相同。两种方法的原始图、gate、draw数、encoder、目标及训练预算匹配。path在三个案例都把更大候选概率质量分配给一阶未覆盖的社区，并同时获得更高的ARI和跨社区同类整合。这是本轮最清晰的方法辨识证据：沿已有局部连接组织候选及其权重，能够触及直接增加k时仍较少接触的群体关系。

这里的概率质量是候选分布，不能与E5真实有限次抽样后的混合权重混写。Kwide与path的来源权重/实际扰动方向也不同，实验支持整个来源组织机制，不能单独归因于“路径身份”。实际位移文件被保留；历史锁定path缺完整trace时不填造数值，也不宣称匹配了实际位移。

## 全队列已有深度背景

复用既有固定有效参数记录得到236个完整三seed深度组，覆盖59个数据集：H1/H2/H3/H4/H5/H6/H7/H8分别59/36/27/25/23/24/15/27组。热图明确标记缺失，不为补齐图而训练所有数据集。H1没有高阶来源，其不生效的q值差异按实现等价忽略；H2以上严格固定q、amplitude和宽度。历史热图readout与本轮重新计算的E3 readout分开记录。

产物：outputs/E2_E6/{case}/summary.csv、per_seed.csv、coverage_by_anchor.csv、coverage_summary.csv、readout_predictions.npz、depth_and_kwide.pdf/svg/png；同目录cross_coassignment_summary.csv及student_h4_h8_saturation_audit.json；outputs/E2_cohort_depth/为已有记录热图。

正文建议围绕一个机制、三个观察展开：Baron展示新增来源的群体角色；Lung展示扩大有效范围后的额外整合；student展示可达范围饱和。不要把三例写成彼此无关的三个算法机制。
