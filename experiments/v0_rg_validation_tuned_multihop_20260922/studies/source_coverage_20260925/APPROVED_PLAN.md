# 多跳 ToPoGate：从有效来源覆盖到群体聚合的研究计划

日期：2026-09-25。范围：V0_RG 的现有多跳扩展，不涉及 V16 系列。原计划已保留；本文件为交叉审阅后的方案，不表示下述新实验已经完成。

## 1. 判断与论文主线

原计划值得推进。最有价值的方向不是继续寻找“更大的 H 可以提高 ARI”，而是回答：**当一阶邻域只覆盖同类群体的局部片段时，如何扩大训练所接触的来源，同时让表示仍以当前样本为恢复依据？**

建议主线：**拓展来源覆盖与保持恢复目标的分离。** 精确图距离分层控制来源范围，邻域扰动让模型接触局部之外的样本，原样本恢复目标约束表示学习。我们研究这套组合是否有助于减少同类群体的拆分，以及这种收益出现在哪些数据结构中。

这是一条待检验的机制解释，不预先声称“所有碎片化数据都受益”“适用性已经可预测”或“其他数据不受损”。已有 Baron 证据足以支撑引言动机和探索性案例分析，论文初稿可以立即开始，不必等全部实验结束。新增实验用于把设计理由变成更强的证据。

### 可直接用于初稿的动机草稿

局部相似性为聚类提供了可靠的邻域关系，但高局部一致性并不保证对完整群体的充分覆盖。当一个群体分布于多个局部区域时，限制在直接邻居中的训练信号可能不足以表达这些区域之间的关联。扩大来源范围又需要决定如何使用新增样本：远处样本可以作为传播、对比或扰动的依据，这些用途对表示施加不同约束。ToPoGate 探索其中一种选择：沿局部图关系分层获得远跳来源，将其用于训练输入扰动，并保持原样本作为恢复目标。我们由此研究来源覆盖与样本恢复约束的协同作用，并通过逐类拆分、跨片段来源及表示几何分析解释其聚类收益。

“可能不足”是问题假设；不能把所有一阶方法都描述为必然碎片化，也不能把所有扩散方法描述为必然过度平滑。

## 2. 先修正方法事实

| 内容 | 与当前实现一致的描述 |
|---|---|
| H | 冻结图上的最大精确最短路径阶数；有向/对称化规则必须随实验记录 |
| S_h(i) | 与 anchor i 的图最短路径距离恰为 h 的候选集合，非任意 h 步游走的访问集合 |
| 壳层先验 | 一阶相对质量为 1，非空 h≥2 壳层相对质量为 q，再归一化；仅 q=1 时等壳层质量 |
| P^h | P 是图转移矩阵；其 h 次幂分数用于壳层内候选截取和采样概率，不是仅用于排序 |
| B、m | B 控制候选截取宽度，m 是实际抽样/混合来源数；扩大候选数不等于增大 m |
| a、gate | a 为已有配置中的扰动强度乘子，gate 为实现中的样本缩放；记录实际有效分布，不统一宣称 ≤0.15 |
| 实际来源贡献 | 当前采样及混合包含按概率抽样后的概率再加权，实际贡献未必等于壳层先验；必须实测 |
| 恢复目标 | 原始 anchor 的模型输入表征，而非假定存在的无噪声真值 |
| 推理 | 使用原样本的 encoder embedding 和 KMeans；当前实现不需要推理时图传播 |

特别注意：跨片段指同一图内可达的局部区域/社区，不是跨越原图不连通分量；增加 H 不能连接原图中不可达的节点。若旧片段定义为类内诱导图分量，连接路径可能经过其他类别，必须报告路径中间节点组成。

## 5. P0：零新增 encoder 训练的重分析

### P0.1 数据清单与分数隔离

拟新增 `audit_readout_manifest.py` 和 `export_validation_scores.py`，不覆盖旧 CSV。输出每个 embedding 的路径/hash、数据矩阵及行序 hash、实际配置、训练 seed、split hash、readout 参数、成功状态和标签审计。

以有效配置与 embedding hash 去重；同名配置不能默认等价，最新失败不能覆盖较早成功。先检查所有数据来源是否唯一或内容一致。选择器只能读取 `scores_val.csv`，冻结选择清单后，单独报告器才读取 test/full 结果。文件隔离降低误用风险，不会抹去既往结果暴露。

明确 K 来源：若取真实类别数，写 benchmark oracle K。完整 X 可用于 transductive 无标签拟合，训练不使用类别标签；validation ARI 选参属于标签辅助模型选择，不能称全过程无监督。

### P0.2 统一选参与预算敏感性

对每个配置先在 readout 内平均，再对三训练 seed 平均 validation ARI，每个数据集选一个配置，而非每个 seed 各选一个。缺三 seed 的配置先排除并列清单；不得凭其较少重复中的高分获胜。

同时输出三种比较：

1. H1 最优 vs 含 H1 的全部路径空间最优：实际搜索收益，明确包含预算差异。
2. 等配置数量子搜索：设 b 为该数据 H1 有效配置数，固定抽样 seed，比较 b 次 H1 候选与 b 次多跳候选搜索；重复1000次，报告分布。同时画预算曲线。既有配置由历史自适应搜索产生，此分析仍是回顾性敏感性检查，不是严格随机化等预算实验。
3. 公共多跳策略 vs 配对 H1：只用跨数据可用的共同策略，如 H4/H8、同 B/q/a。其余 backbone 参数若因数据不同而不同，必须称“共享路径策略”，不能称完整模型全局同一配置。

第三项使用按独立研究分组的 leave-one-dataset/group-out，在其余数据的 validation 上选择路径策略。只有共同网格覆盖、配置和种子完整时才能零训练实现；否则输出覆盖矩阵，补缺或缩小共同网格，不做结果插值。旧结果曾参与方案设计，LODO 仍是探索性迁移估计。

输出：`selection_lock_v2.json`、`search_budget_curve.csv`、`shared_policy_lodo.csv`、每数据完整得分及缺失清单。旧10-readout用于复用选参；新确认实验固定20-readout。平均 ARI 为主要表示评价，最小 inertia 方案为独立部署终点；比较双方 n_init、总初始化次数和计算预算一致，不混用两个选择目标。

### P0.3 从“有多远”改为“新增覆盖了什么”

冻结原始图和一种不依赖标签的社区划分；分辨率、随机 seed 预先固定。计算：

- 同一实际来源数 m 下，H1/H8 的跨社区有效质量、来源社区熵、独特供体数和有效样本数。
- 精确壳层与 h 步随机游走的图距离分布：游走访问近层的比例、真正新增社区覆盖。
- 按 anchor 展示 H1 未覆盖、远跳可达的社区；“远跳不属于H1”按定义成立，不把这一点当作新发现。
- 标签仅用于事后标注社区的类别组成、同类跨片段来源质量、类别拆分和异类合并变化。大类和小类分别汇总，避免只由最大类驱动。

如果已有轨迹不足，使用固定 Monte Carlo 重建并报告误差，不把重建称为历史真实训练轨迹。

输出：各案例“anchor→来源社区→类别组成→H1/H8错误变化”对应表；同一固定布局上的来源图；跨片段共同分配热图。UMAP 只帮助定位，结论来自原图和原 embedding 的定量统计。

## 6. P1：最有信息量的新实验，先做50次而非数百次

### 核心问题

**远跳来源的分配方式，是否在“恢复原样本”这个目标下更有价值？**

选择 Baron 加一个第二案例（worm 或 Campbell，按 P0 冻结规则确定），每数据5个新训练 seed，执行以下五臂，共50次训练：

| 臂 | 候选来源 | 壳层先验 | 恢复目标 |
|---|---|---|---|
| A | H1 | 一阶 | 原样本 |
| B | 同一精确多跳候选集合 | 非衰减，冻结 q | 原样本 |
| C | 与 B 完全相同 | 截断并归一化的几何壳层先验 | 原样本 |
| D | 与 B 完全相同 | 与 B 相同 | 混合后输入 |
| E | 与 B 完全相同 | 与 C 相同 | 混合后输入 |

B/C/D/E 构成来源先验×恢复目标的2×2设计。主要比较 B−A；机制比较 B−C、B−D 及交互 (B−C)−(D−E)。这些是事先指定的问题，正负结果都报告。C/E 是几何壳层先验对照，**不是完整 PPR/APPNP 实现**，不能以它们较差宣称优于 PPR。

统一 encoder、图、k、B、m、mask、优化器、epoch 和 paired seed。对 H1/H8 在新执行器中的无干预路径先做等价性检查；旧 checkpoint 不用于替代新执行器 reference 的关键因果对照。保存每次权重、实际抽样轨迹及配置 hash。

主要五臂采用相同名义强度，记录实际位移；这检验整体设计差异。若 B/C 位移分布明显不同，再做**独立的等幅敏感性臂**，仅用无标签 X 校准缩放，并报告位移分布、余弦方向、裁剪及零位移处理，不能声称主设计已经排除了幅度因素。按幅度筛选结果或临时重调至有利方向均不可。

几何先验的 α 预先固定为0.2作机制对照，另以0.1/0.5的无训练来源统计检查敏感性。该固定参数臂不代表最优扩散基线。若用于方法性能比较，需在开发数据给其匹配的validation调参预算。

### 允许调参，但服务于问题

第一阶段优先从已有配置选，不新增大网格。候选路径 H∈{2,4,8}，q∈{0.5,1,2}；宽度 B 和强度 a 使用已有成功范围，先固定，再做一维敏感性。实际参数合法性以当前代码为准。

每数据有限预算至多12个候选配置，三训练 seed、固定10-readout validation均值选择；H1 获得同量的有效训练/强度配置预算。历史有完整匹配配置的直接复用。选择规则、平分 tie-break、失败处理预先锁定；相同分数优先低 H、低成本，不根据 full/test 的改善选择。5个新 seed 用于锁定配置复现，不再返调。

种子清单生成前检查与全部已有实验无重叠，写入冻结清单。每项成本分别记“已有复用、候选校准、新确认”，50次只指核心五臂，不包含可选调参。

## 7. P1：把远跳来源解释到数据本身

### Baron 的逐样本机制分析

先冻结 beta 类和原片段定义，再对全部 anchor 分层分析，不仅挑几张漂亮图：

1. 覆盖：远跳来源来自哪些 H1 未覆盖的局部社区？是否同一 cell type、不同 donor/batch 或不同局部状态？
2. 表征：这些来源在已注释 gene program 或固定 gene set 上有哪些差别？先核对 gene ID 与预处理；若只有匿名 PCA 特征，只能解释为特征方向，不能命名生物程序。
3. 聚合：跨片段共同分配概率、类内分片率、异类合并率、归一化类内半径和最近异类 margin 如何改变？
4. 对应：来源覆盖更充分的 anchor，是否出现更大的跨片段共同分配改善？控制 H1 局部密度、类频率和初始错误，按训练 seed/社区汇总，不把大量样本对当独立重复。
5. 若 donor 元数据存在，区分同类跨 donor 聚合和异类过度合并；没有该元数据就不推断 batch removal。

生物学富集仅为来源解释，不能进入供体选择或模型调参。禁止为了本轮“机制成立”而让真实 cell type 标签控制训练供体；可以在固定 embedding 上作标签后验分层。

### 可选的局部结构干预

若以上对应关系清楚，再在不使用类别标签的条件下，限制跨社区远跳来源，与保留这些来源比较；保留候选数并报告来源熵/位移变化。它检验图社区覆盖，不等于“同类信息”的单因素干预。先做一个数据集，避免大量拆臂。

### KMeans 多峰如何写成有价值的结果

固定 embedding，记录各初始化的 inertia、ARI、coassignment。比较达到正确群体聚合的初始化比例、低 inertia 区域中不同划分的竞争情况、最小 inertia 解与平均解的差距。**若多跳提高好解出现概率，这是可报告的 readout 稳健性收益；若只提高单次峰值，则是最优可达解改善。** KMeans 对随机种子敏感本身不能证明远跳特征有效，需要 H1/H8 成对比较其分布。

## 8. P2：小规模独立确认与最近邻相关工作

核心五臂之后，新增3–5个经来源审计的独立数据集，每个 H1/共享多跳策略×5 seed，共30–50次训练。冻结路径策略、预处理政策、K来源、readout、主终点和失败处理。可采用全 X transductive 评价，但不按这些数据标签再挑配置。研究不以达到某个 p 值后停止；报告全部预定数据和不确定性。

外部比较优先 scHNTL 官方实现：它已经使用高阶邻居和 triplet loss，不能把“高阶邻居”本身当创新。其次 scNAME、MAGIC+KMeans，以及共享 backbone 的平滑输入对照。scTACL 2026 加入相关工作核对，是否跑基线取决于公开代码可复现性与任务匹配。不要用自写“donor-positive”简化臂代替官方 scHNTL。

方法原生预处理与统一输入比较分开报告；同一评分协议、K来源和预算可统一，不强行破坏模型必需的输入分布。旧56模型汇总用于背景，只有协议可比的重评结果才能支持严格方法排名。CLUBench 有 best HPC 汇总，但这不足以宣称比较对我们“偏保守”。

跳数曲线为可选补充：H∈{1,2,4,8,12}，先复用，先画有效覆盖及表示指标，再决定缺少哪些训练。横轴分清图最短距离上限与扩散步数；不预设平滑基线必然下降。

## 9. 无标签适用性规则是加分项，不是论文的前置条件

最多预选3个输入特征：固定社区划分下的跨社区新增有效覆盖、壳层可用性、H1 readout稳定性。不要把按定义互斥的壳层“新颖性”当有效预测量。

若拟合收益预测器，目标来自标签评价，所以整个规则的开发并非无监督；只能说应用时不读目标数据标签。标准化、特征选择、阈值和模型选择全部在按独立研究分组的 nested CV 内完成。不能先用所有数据确定最佳特征再做 LODO。数据集才是跨数据推断单位，不把 seed 当新增数据集。

若预测能力有限，保留结构解释和案例研究即可，不必为“自动判定适用性”再增加一个复杂模型。无差异的 p>0.05 不等于不受损，本计划不以普遍非劣效作为必须主张。

### 可选：为方法章节提供更直接的表示学习解释

令 f 为 encoder 与 decoder 的复合映射，δ 为实际邻域扰动。对光滑映射的小扰动，f(x+δ)≈f(x)+J_f(x)δ，其中 J_f 是 Jacobian。原样本恢复损失因此会约束模型对实际来源方向的响应；来源变化对应不同的扰动方向分布。这给出“来源选择为什么可能影响聚合”的分析入口，而不要求声称远跳补全了缺失特征。

该近似只解释平方恢复损失的局部行为；非零均值扰动会产生残差交叉项，不能直接等同于纯Jacobian正则。实际mask、损失形式、扰动尺度及非线性必须在正式推导中核对，不能把这个直觉写成已证明定理。

低成本验证：冻结H1/H8模型，对相同的一组真实来源位移及等范数随机方向，作有限差分响应曲线。分别报告恢复误差变化、归一化embedding响应，以及同类跨片段/异类来源的事后分层。如果H8仅对有用来源方向更稳定，同时保留异类分离，这将把“输入端收集了谁”与“表示端为何改变”连接起来；若所有方向一起收缩，需检查是否只是整体尺度变化。这是P0后优先于大规模新增跳数的可选实验。

## 11. 交叉审阅意见的取舍

Claude Opus 5.5 第一轮给计划6/10、almost ready。该评分针对方案可执行性，不是录用概率。其主张、脚本审计和最近相关工作建议已吸收，但以下建议未直接采用：

- 不把无跨片段质量的 Mast 细胞类当独立数据集或断言它不会受益；其他机制仍可能起作用。
- 不因脚本有结构缺陷就判定全部数值不可信；先核验并安全复用。
- 不把旧负向新seed实验与本轮正向历史seed实验的差别直接归因于readout；必须先核对模型、配置、seed和文件。
- 不采用真实类别控制供体的训练敲除作为主实验，保持 label-free fitting。
- 不宣称用LODO已证明无标签适用性，不用“新增覆盖率”这种定义性指标替代有效覆盖。
- 不因样本量少而放宽成功判据至置信区间略小于零；效应不确定就如实报告，不将其称为确定正收益。
- 不直接上约400次训练；优先零训练分析与50次核心因子实验，再按信息缺口扩展。

## 12. 核实的相关工作入口

- scHNTL（2025）：https://doi.org/10.1093/bioinformatics/btaf044 。高阶邻居用于triplet学习；需逐项核对其最短路径定义，因此不能主张精确壳层本身首次提出。
- scNAME（2022）：https://pubmed.ncbi.nlm.nih.gov/34999761/ 。mask estimation和neighborhood contrastive learning。
- GDC（2019）：https://arxiv.org/abs/1911.05485 。广义扩散包含不同核，并非全为几何衰减。
- MAGIC（2018）：https://doi.org/10.1016/j.cell.2018.05.061 。使用扩散算子幂作用于特征，并非本计划的几何壳层先验。
- scTACL（2026）：https://doi.org/10.1093/bioinformatics/btag361 。加入topology-aware augmentation/contrastive相关工作审查。
- CLUBench（2026）：https://arxiv.org/abs/2605.29933 。基准协议与best-HPC汇总需要独立对齐，不能从公开表直接推断严格SOTA。
