# 本轮执行要求与预期（冻结前整合）

本轮核心问题：图上远跳样本是否扩展了有用的来源覆盖，以及这种覆盖为什么需要原样本恢复目标约束，才能转化为更完整的同类聚合。

| 步骤 | 操作与保存结果 | 预期可辨别的结论 | 防止错误解释 |
|---|---|---|---|
| P0 选择审计 | 60个历史数据集，配置规范化、validation锁定、同搜索预算敏感性、全部数据结果表 | 区分搜索机会、路径选择与平均readout收益 | 历史优势是发现背景；全部配置full/test分数不用于改锁 |
| P0 来源覆盖 | 六案例固定图社区、anchor与远跳来源、同类拆分/异类合并、源社区与特征差异 | 识别哪些局部群体在H1中覆盖不足，以及多跳实际新增哪些来源 | 图社区不是cell type；图距离不是生物距离 |
| P1 核心五臂 | Baron与worm_neuron_cell，各5个新seed，H1、flat/geometric×anchor/mixed，共50次；保存全部权重及真实采样轨迹 | 检验来源先验、恢复目标及两者交互，而非仅展示H更大 | 五臂同backbone、图、训练预算；实际位移另报，不能假定等幅 |
| P1 聚合与readout | 每训练seed固定20次KMeans，n_init=20；逐类拆分、合并、几何、共同分配概率 | 判断改进来自好划分更常见、几何改变，还是仅单次峰值 | readout不是独立训练重复；不以最大ARI选结果 |
| P1 方向响应 | 同一anchor、来源方向及等范数随机方向，比较冻结encoder对扰动的响应与原样本恢复误差 | 远跳来源方向是否形成有区别的表征响应与恢复约束 | 单个donor方向不等于完整训练混合位移；不用此探针宣称真实去噪 |
| 最近方法对照 | scHNTL官方源码，运行时兼容桥，5seed；同细胞与选定特征，保留原生预处理 | 与高阶邻居triplet学习比较，区分“用高阶邻居”和“以邻域扰动约束恢复” | 原生预处理、预算、K来源和运行时差异显式列出；不由单对照宣称普适SOTA |
| P2 固定策略迁移 | Pollen、Wang、hrvatin_geo候选，各H1/固定多跳×5seed；参数不看候选标签调整 | 在额外可取得数据上检查共同的覆盖/聚合现象，扩充适用范围 | 当前研究独立性未完全核验，标为探索性迁移；相同整数行号不证明样本重复 |
| 汇总 | 每步CSV/JSON、图、失败日志、审计、中文FINAL_ANALYSIS.md | 形成“数据局部覆盖不足→远跳来源参与→恢复约束→聚合改变”的有条件证据链 | 同时说明一致结果、异质现象、未测到的语义；不把未知写成否定结论 |

正式执行要求：父代理审查并绑定code/queue/task哈希；Baron、worm真实矩阵的H1和flat路径短跑与原始实现逐值一致；拟合无标签，K为明确记录的benchmark oracle。GPU仅2/3/4/6，按空闲显存和利用率增并发，保留其他任务。每任务最多3次尝试，失败归档，独立任务继续；不替换失败seed。

阶段允许的不同结果：若flat优于geometric且anchor优于mixed、交互同向，支持覆盖与恢复约束的联合解释；若只有来源先验差异，重点写来源组织；若主要是readout分布改善，聚焦好划分的可达性；若个别类别出现分离收益，单列为分离机制，不硬并入同类聚合。
