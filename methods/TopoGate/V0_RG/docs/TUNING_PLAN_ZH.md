# ToPoGate：CLUBench 与生物数据集统一调参计划

## 目标与可支持的论文结论

在同一主干、邻域损坏算子和锚点恢复目标下，逐数据集选择边权调制、门控幅度和训练参数。常数门控属于统一模型的参数子空间；允许边调制与节点门控交叉组合。验证标签用于超参数选择，标签不进入网络拟合；最终测试成绩用于评价。该协议可以评价统一模型经选参后的性能，不预先保证优于两套历史配置、所有基线或达到发表标准。

模型名称统一为 ToPoGate。代码中的 `rg_full` 保留为向后兼容的启用邻域任务标识，不意味着必须使用拓扑调制。每个数据集发布完整冻结配置，不能通过测试 ARI 在两条历史结果之间取最大值。训练损失、网络容量和数据协议共同固定后，配置互补才具有可解释性。

## 一、固定数据清单

1. CLUBench 主面板为官方 131 数据集，锁定仓库版本和实际输入文件 SHA256。原始表示与预训练表示是独立、具名输入条件，同一比较中各方法获得同一矩阵。主面板完整报告，按表格、文本、图像及原始/预训练输入分组汇总，不按 ToPoGate 成绩删除数据集。
2. 生物面板以已有数据为候选池。上传汇总包含 26 个不在 CLUBench 档案名称集合中的名称，加上 CLUBench 中的生物数据，必须按原始研究、样本身份和特征版本核实后确定最终数量。Baron、Baron_Human、Baron Human，以及 hrvatin 的不同版本不能凭名字判为独立任务，也不能未经核对合并。
3. `dataset_inventory.csv` 列出上传汇总中的 157 个名称，131 个来自 CLUBench 档案，26 个为额外候选。这是覆盖清单，不能代替可执行 manifest。每项需填实际路径、input_kind、已登记 K、panel、source_group 和 representation。不得猜测生物输入是原始计数还是已取对数。
4. 同源重复样本不在整体宏平均中重复加权；不同表示版本保留单独结果，并额外报告按 source_group 聚合的结果。不同文件哈希不等于样本独立。
5. 不足 10 行或登记 K 大于训练样本数的任务标记不适用此划分协议。所有其他失败报告原因和覆盖率，不把缺失结果当零，也不静默从分母删除。类别极稀少时记录测试类别覆盖和样本量，避免对单个小测试集过度解读。

## 二、先消化历史实验

上传 `library_cross_all_20260909(1).tsv` 有 4,166 行、82 个方法标识、157 个数据集名称；列仅为 model/dataset/ARI/NMI/ACC/seeds/protocol。它缺少完整配置、样本索引、输入和代码指纹，因此不能自动复用其中任一行为本协议的正式运行。这不等于底层运行无效。

- 正式复用要求：原始数据、样本划分、特征选择与缩放、网络代码、完整配置、随机种子、读出拟合范围和评价集合均可核对一致。
- 可恢复参数但协议不一致：只将参数作为 warm start，重新运行验证。manifest 的 `warm_start_configs` 接收搜索参数字典，每个预置配置计入同一 32 候选预算，不接受 epoch/主干/预处理变更。
- 其余旧结果保留为探索记录。禁止按“五种子优先”覆盖不同协议，也不能从测试最高的历史版本自动导入候选并声称该测试集从未参与开发。
- 跨历史结果比较需要保留协议维度；82 个方法标识不等于 82 个独立算法。附带的 historical_inventory.json 记录来源哈希与协议计数。

已有测试结果曾影响模型开发，重新随机划分不能彻底消除历史开发偏差。正文明确数据的开发使用史；新增、未参与开发的生物研究可提供更强的外部证据。

## 三、统一实现与参数含义

邻域估计为加权邻居特征，输入为 x'=(1-g)x+g*neighbor。解析门控的上下界可由中心 g0 和自适应幅度 r 表示：

- g_min=g0(1-r)，g_max=g0(1+r)。r=0 精确产生常数门控。
- 旧 gate_min/gate_max 仍被支持；同时显式设置两套参数会拒绝，避免覆盖歧义。
- edge_reliability_mode=none 精确恢复基础图概率；开启时支持原有互邻与共享邻域调制。
- auxiliary_weighting=gate 为主协议，保留论文的门控加权辅助损失。uniform 仅作机制消融。
- neighbor_estimator=current 为主协议，保留有放回概率采样后再加权；uniform_sample 和 full 作为预先限定的估计器消融，不在本轮主搜索中切换。

四个预置候选为：基础边权+常数门控、原拓扑边权+自适应门控、拓扑边权+常数门控、基础边权+自适应门控。预置常数候选使用 k=5/m=4/g=0.1，拓扑候选使用 k=10/m=4/g∈[0,0.15]，其余沿用 base 配置。它们对应原控制机制；与历史 PlantNet 完整训练的随机流、drop_last 和预处理不保证逐位复现。既有旧配置若不同，应从审计记录导入 warm start，不以这里的默认值冒充旧最优参数。

## 四、逐数据集独立选参协议

- 每个任务固定一次 60/20/20 样本划分，split_seed=9102026；划分仅依赖样本数和随机数。所有候选、基线、正式种子使用相同索引。有预先定义的受试者/批次独立预测目标时，需要另建分组划分协议，不能把当前随机样本划分称为跨受试者泛化。
- 调参时仅在 train 拟合预处理、PCA近邻图、网络和 KMeans 中心，validation 只做变换、编码、中心预测和评分。
- 生物 raw_count：逐样本总量归一化至 10000、log1p，再在 train 选择最多 2000 高变基因；已 log1p 表达不重复取对数。HVG 使用 Seurat，退化时采用已记录的方差回退。
- general：保留带负值的输入。若超过 2000 特征，仅根据 train 方差选择 2000 特征；否则保留全部。所有面板在 train 拟合 StandardScaler 后应用于 validation/test。这是本轮明确的模型输入协议，不能声称直接处理全部原始基因维度。其与旧不中心化/全特征实验分开记录。
- K 从任务 manifest 给定，网络不使用 K，聚类读出使用已知 K；登记表仍属于已知簇数条件。
- 统一 80 epoch、hidden=128、batch=256、dropout=0、位置重构权重=0.75、掩码任务权重=0.70、PCA维度最多50、KMeans n_init=20。小样本实际近邻数取 min(k,n_train-1)。
- 不使用早期重构损失淘汰候选。第一轮全部候选跑满同样的 80 epoch，避免此前 epochs 伪差再次进入选择。

| 搜索量 | 本轮范围 |
|---|---|
| g0 | [0.02,0.20]，对数 |
| r | 0 / 0.25 / 0.5 / 1 |
| k | 5 / 10 / 20 / 30 |
| 采样邻居数 m | 2 / 4 |
| 边调制 | 关闭 / 开启 |
| gamma_mutual、gamma_snn | 0 / 0.5 / 1 / 2 / 4，仅开启边调制时 |
| beta_mutual、beta_snn、beta_perturb | 0 / 1 / 2 / 4，仅 r>0 时 |
| tau | [0.1,1.0]，对数 |
| pseudo_weight | [0.05,1.0]，对数；0 单独作为基础模型对照 |
| mask_ratio | [0.2,0.6] |
| lr | [0.0003,0.003]，对数 |

新增搜索固定 gamma_sim=gamma_distance=0，减少重复的余弦信息缩放；原拓扑预置候选保留旧系数，防止从候选池中丢掉旧控制方式。tau 同时影响基础概率及门控偏离项，因此这里是搜索范围简化，不宣称所有温度替换都保持模型等价。beta_uncertainty 在无不确定性输入时固定为0。

## 五、预算、冻结和停止规则

每个数据集：4 个预置候选（加可核对的 warm start，计入总数）+ TPE 条件搜索，总预算32个候选。TPE 的前8个提案为启动采样；32是可执行的首轮预算，不是充分找到全局最优的理论保证。

1. 初筛：每个候选 seed=42、80 epoch，最多32次训练。
2. 复验：验证 ARI 前4名补充 seed=123、7；按三种子平均验证 ARI 选唯一配置。并列按较低种子标准差，再按稳定配置哈希排序；不借助测试 NMI/ACC 解并列。最多增加8次训练。
3. 冻结：写 selected.json，包括候选完整配置、三种子验证成绩、选择规则、实验指纹和选择哈希。标签记录明确 labels_used_for_selection=true、selection_labels=validation_only、labels_used_during_fit=false。
4. 正式：train+validation 重新拟合预处理、图、网络和聚类中心，test 只预测评价；种子42/123/7/2025/3407，共5次。报告测试ARI/NMI/ACC均值和样本标准差。
5. 正式开始后同输出目录拒绝重新搜索。改变代码、数据、划分、预算或环境需要新的实验身份，并且必须说明测试成绩是否已参与后续开发，不能借新目录声称重新获得独立测试。

每任务主模型最多45次训练，131个CLUBench任务为5895次；生物去重后额外B个任务为45B次。重复配置可复用，失败不会自动追加预算。对照、消融和试运行另计。先在3个按输入类型预先选定的任务上测量耗时和显存，完成同一协议的运行检查，再展开全库；这3个任务不能按最后成绩更换。当前命令按任务顺序执行，可在服务器按dataset_id分配独立进程；同一任务目录仅允许一个写入者。默认CPU，GPU需要显式指定，不隐式占满设备。

## 六、论文对照和机制证据

完整主表保留每个任务的冻结单一ToPoGate配置。全库核心对照为同主干scMAE、同协议常数配置、同协议拓扑默认配置、同输入KMeans及PCA+KMeans。常数限制族也要获得与统一模型相当的调参机会，才能把优势归因于额外控制能力而非搜索预算；默认常数对照只能支持“相对默认设置”的结论。对照选参应具有相同验证标签访问和明确预算。其他深度基线优先选择方法相关、可按同协议编码并读出的代表方法，报告其各自预算，避免扩展到82个历史标识。

CLUBench best-HPC全数据档案保留为背景表，与本计划独立测试结果分开。谱聚类等没有直接样本外预测接口的方法应采用预先定义的样本外扩展并披露，或只在单独传导面板比较，不能偷偷在test重新拟合后加入归纳主表。

机制消融只在冻结配置上改变指定模块，不重新调参：关闭辅助项、关闭边调制、以训练平均门控替代逐样本门控、保留输入门控但辅助损失等权。常数门控替换会同时改变输入及门控加权，后一个对照帮助区分两者。记录门控均值/分布、有效邻居数、实际输入位移、损失和表示方差。full/uniform_sample估计器作为有限的补充消融；不为追逐测试最优不断增加结构。

汇总按每个数据集等权，分别报告131主面板与生物面板平均指标、平均秩、配对差值、胜/平/负和完成率。模型间配对在数据集层面进行，同源任务聚合后另作核对；五个种子不当作五个独立数据集。论文可写“统一模型、逐数据集验证选择的参数”，同时说明验证监督与已知K。不能宣称完全无标签自动选参，也不能预写所有数据集更优。

## 七、执行入口与产物

安装仓库原有依赖并额外安装 optuna。填写并核实 `configs/tuning_manifest.example.json` 的实际副本；示例不是全库真实路径清单。模型支持稠密/稀疏NPZ、NPY、数值CSV/TSV；原生H5AD需先通过已有数据转换流程导出矩阵和对应标签，不自动猜测obs字段。

```bash
python -m methods.TopoGate.V0_RG.tuning --manifest /absolute/path/manifest.json --output-dir /absolute/path/result/topogate_unified_v1 --stage search --device cuda --gpu 2
python -m methods.TopoGate.V0_RG.tuning --manifest /absolute/path/manifest.json --output-dir /absolute/path/result/topogate_unified_v1 --stage final --device cuda --gpu 2
```

可加 `--dataset-id ISOLET` 执行单任务。搜索与最终评价必须使用相同的epochs/trials/feature-limit/split-seed/search-seed和设备设置，以使身份匹配。不要将冒烟实验的 `--epochs 1 --trials 4` 结果用于论文。

每任务产物为 experiment.json、split.json、selection_preprocessing.json、validation/、search.db、selected.json、final_started.json、final_preprocessing.json、final/、final_summary.json。缓存以数据/代码/配置/环境/划分指纹核对后复用，失败写明确记录并退出该任务。搜索已经冻结时重新执行search会拒绝；处理多数据集时可用dataset-id继续尚未完成的任务。恢复中断的TPE保留已有候选/预算，后续提案不保证与从未中断的随机序列相同，实际全部trial都被保存。

训练器默认入口仍是历史全数据拟合；独立测试论文实验必须使用新的tuning入口。旧脚本引用的scripts/V0_RG及V0_RG_rg_adapter未在当前仓库提供，不能把旧入口当作本轮可运行依赖。新入口仅依赖当前模型目录及已有NeighborMix主干。

## 方法依据

- CLUBench: A Clustering Benchmark, 2026：131数据集、多类算法、调参及表示条件对评价的影响。https://arxiv.org/abs/2605.29933
- Cawley & Talbot, 2010：验证准则可过拟合，选择偏差需要与最终评价隔离。https://jmlr.org/papers/v11/cawley10a.html
- Deep Clustering Evaluation: How to Validate Internal Clustering Validation Measures：不同嵌入中的内部指标可误导比较。https://arxiv.org/abs/2403.14830

这些依据支持评价协议；它们不证明ToPoGate经过本轮搜索后一定达到预期性能。
