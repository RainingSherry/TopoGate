# corruption_objective_compatibility_probe

This independent, non-V-series mechanism study asks whether the closed C2
`P2_SupportTarget` observation survives a cross-domain sentinel panel and
whether it authorizes an objective-specific follow-up. It is not a support
causality study or a new TopoGate/backbone search.

The frozen E0–E4 protocol completed E0, E1, E1b, and E3. E1/E1b are
`54/54` complete; none of the three non-biological sentinels passed the
pre-registered cross-domain opportunity gate, and only one passed the
training-amplification margin. The E2 objective matrix was therefore not
launched, and the terminal decision is `STOP_GENERAL_CORRUPTION`.

[Protocol](PROTOCOL.md), [pre-registration](PRE_REGISTRATION.md),
[E1 report](E1_RESULTS.md), [integrity audit](E1_INTEGRITY_AUDIT.md), and the
[terminal decision](../../result/corruption_objective_compatibility_probe/FINAL/OVERNIGHT_DECISION.md)
define the evidence boundary. Only compact, metadata-only results are
published; raw data, labels, arrays, embeddings, predictions, checkpoints,
weights, logs, and intermediate run directories remain excluded.
