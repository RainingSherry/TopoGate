# raw_sparse_mask_schedule_probe

An independent, local-only six-sentinel mechanism study of raw zero-preserving
mask targets and fixed versus variable mask schedules. It is deliberately not
a V-series project and does not modify the earlier TopoGate lineages.

Run the contract check with:

```bash
python -m scripts.raw_sparse_mask_schedule_probe.protocol --validate
```

The current execution amendment is documented in
[`CLEARANCE_E1_E12_20260819.md`](CLEARANCE_E1_E12_20260819.md) and uses
[`PROTOCOL_V2_SHARED.md`](PROTOCOL_V2_SHARED.md). It clears the selected
resource gates while retaining GPU 0/7 prohibition, label isolation, failure
audits, and provenance. v1 remains a historical record and is not mixed with
v2 results.
