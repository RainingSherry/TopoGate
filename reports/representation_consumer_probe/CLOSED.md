# `representation_consumer_probe` — project closure

**Status:** CLOSED (2026-08-17)

The independent representation-consumer study is formally closed after its
frozen S0 → S1 opportunity-only Spectral matrix → conditional S2 SimpleCut
confirmation. Its terminal state is:

```text
opportunity_status = heterogeneous_with_spectral_relaxation_caveat
selector_status = not_estimable
representation_consumer_promotion = not_authorized
```

The study established only that the frozen relation family contains observed
reference opportunity on some datasets, that Spectral can miss a near-threshold
case on Baron Human, and that Mouse_retina remains observed-small under both
consumers. It did not estimate TopoGate selector utility, `S_graph`, a new
backbone advantage, or holdout generalization.

The S0 adapter audit remains `adapter_not_estimable`. S3–S6, TopoCut, and any
new selector are permanently locked in this project. No old S0/S1/S2 artifact
is modified to support a later claim.

Future work on sample-sample relation selection starts as the independent
`relation_selection_probe` project. It may read the audited S0 H0/candidate
artifacts and the S1 `R`/`O_pool` reference artifacts, but it owns a new
protocol, estimands, code path, result tree, and decision boundary.
