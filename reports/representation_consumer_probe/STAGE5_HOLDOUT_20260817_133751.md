# S5 — Frozen Holdout Confirmation

六个压力数据集只用于机制定位，不承担 generalization claim。S5 必须在查看 S3/S4 的 holdout-like outcomes 前冻结新的 12-dataset manifest。

## Holdout selection

从 repository dataset universe 依据 label-free characteristics 选取覆盖广的 12 个数据集：`log n`、`log d`、sparsity、intrinsic-dimension proxy、nearest-neighbor distance profile、candidate connectivity。先冻结 source/adapter/K/resource preflight；不得依据历史 ARI、V21 sign、V25 failure label 或本项目 pilot outcome 选样。

selection algorithm、feature standardization、farthest-point/clustering seed 和 dataset exclusion rule 写入 manifest；如资源边界导致无法完成，必须写 `incomplete_compute`，不能换更小数据或删掉难例后继续汇总。

## Confirmation

只运行 frozen S3/S4 config，确认 seed 固定为 `[42,123,7,3032,3033]`。不存在三 seed fallback；资源不足时保留 `incomplete_compute`，不减少 denominator。禁止调 architecture、loss、edge budget、embedding dimension、learning rate、epoch、readout 或 dataset membership。

## Endpoints

以 dataset 为统计单位报告：

- median/mean `I_d`；
- positive/tie/loss counts；
- 三 seed direction-stable count；
- TopoCut topology-specific contrast 与 shuffle gap；
- completed/incomplete/invalid denominator。

不以 `p<0.05` 替代 effect size。只有当 frozen holdout 总体 interaction 与 topology-specific controls 方向一致时，才允许 S6 paper-scale expansion；否则 downgrade claim 并关闭路线。
