# D0 Freeze

D0 is a non-training inheritance audit. It verifies the terminal M1 state,
reuses the three audited dense-H0 sources by hash, and freezes the Cross,
Preserve, dose, label and GPU contracts before the feasibility scan.

The compact artifact is
`result/support_crossing_common_dose_probe/D0_freeze/audit.json`.
`audit_ok=true` authorizes only D1 CPU feasibility; it does not authorize D2.
