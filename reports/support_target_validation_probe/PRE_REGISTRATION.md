# Pre-registration: M0/M1

This document freezes the only currently authorized work in
`support_target_validation_probe`.

## Evidence inheritance

The old `sparse_corruption_principle_probe` C2 output is closed and read-only.
M0 must verify its independent integrity audit, 54/54 completed-valid runs,
and all nine C2 P2 summaries. It records H0, budget, C2 summary and source
hashes. No C2 performance run is repeated.

The already selected C2 holdout membership is inherited read-only. M0 must
verify that it was selected before C2, has no development overlap, used no
outcome features or labels, and remains unauthorized for execution.

Because C2 compact artifacts did not save pair identities, M0 independently
replays the old P2 branch with the frozen seed and post-epoch batch permutation.
M1 is authorized only if all nine replay trajectories reproduce the old values,
masks and scalar audit fields.

## Label firewall

`y`, ARI, NMI, ACC and cluster purity are forbidden inputs to corruption,
partner matching, preprocessing, loss, optimizer, early stopping and variant
selection. Labels are loaded only after fit for the outer benchmark-known-K
readout.

## Resource and publication boundary

Every formal subprocess must set exactly one `CUDA_VISIBLE_DEVICES` value from
`[1,2,3,4,5,6]`; physical GPU 0 and 7 are forbidden. No raw H0, labels,
arrays, embeddings, predictions, checkpoints, weights or logs are publication
artifacts.

M2 raw-X bridge, M3 holdout, M4 full-backbone transfer, adaptive policy and
GAN are locked in this protocol.
