# sparse_corruption_principle_probe result root

This result root contains only compact, timestamped protocol/inventory/diagnostic artifacts. Raw
matrices, labels, corruption arrays, embeddings, predictions, weights, checkpoints, logs and caches
are intentionally excluded from publication.

Current artifacts:

- `C0_holdout_inventory/`: outcome-independent holdout membership manifest and audit; runs remain locked.
- `C1_mechanism_audit/`: zero-fit structural replays and compact support/value/geometry CSV.
- `C2_toy_sanity/`: apparatus-only toy artifact when generated; not clustering evidence.
- `C0_C1_CONTRACT_AUDIT.json`: deterministic integrity audit of the compact artifacts.
- `C2_static_matrix/`: compact 54-run summaries, decision and independent integrity audit;
  raw score arrays remain local under the excluded score-artifact directory.

The static-library boundary suite passed `16` focused tests before launch, including small-sample
geometry-kNN and dense-proxy support-target cases. The C2 matrix then completed `54/54`
completed-valid runs with an independent `audit_ok=true` integrity audit. This is a bounded
development-panel result, not a holdout/generalization claim.

The terminal C2 label is `simple_static_principle_sufficient`: P2_SupportTarget is material on
all three development datasets, while P3_FrequencyAware and P4_ResidualHard are material on two
each. C3 holdout runs, adaptive policy, GAN and learned generator remain locked.

Support in C2 denotes the frozen threshold-defined support of dense H0, not raw-X zero/nonzero
support; raw sparse-support claims require a separate validation. Raw input matrices, labels,
embeddings, predictions, checkpoints, score arrays and logs are not publication artifacts.
